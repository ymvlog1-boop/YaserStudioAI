# Yaser Studio AI 0.5.0

هذه نسخة معاد بناؤها حول خطوات عمل المصور، بواجهة عربية RTL ومعالجة محلية. الصور الأصلية لا تتغير؛ البرنامج يحفظ نسخاً جديدة فقط.

## خطوات العمل

1. **الجودة:** إزالة التشويش، استرجاع الحدة، واختيار الحجم الأصلي أو تكبير ×2/×4 عند الحفظ.
2. **الضوء:** التعريض، التباين، الإضاءة القوية، الظلال، الأبيض، الأسود، حرارة اللون، الصبغة، الحيوية، التشبع، الوضوح وإزالة الضباب.
3. **البورتريه:** كشف عدة وجوه، استثناء أي وجه، إضافة أو حذف منطقة البشرة بالفرشاة، قوالب جاهزة، والحبوب والتجاعيد والنمش والتنعيم ولون البشرة واللمعان والهالات والعيون والأسنان.
4. **الرتوش:** فرشاة تفتيح وتغميق وتقوية لون وتنعيم موضعي، وإزالة عيب أو عنصر صغير مع التراجع.
5. **الخلفية:** نموذج MODNet مخصص لقص الأشخاص والشعر، مع إزاحة الحافة ونعومتها وتنظيف لون الخلفية القديمة وضبابية الخلفية الجديدة. فرشاتا «استرجاع من الخلفية» و«حذف من الخلفية» تصلحان الحواف يدوياً.
6. **الدفعة:** طبّق وصفة الجودة واللون والتنقية على كل الصور، واختر مجلد إخراج واحداً، ثم احفظ JPG عالي الجودة أو PNG.

## الجديد في 0.4.1

- سحب الصور أو مجلد كامل وإفلاته داخل البرنامج.
- عرض صور الدفعة كمصغرات مرئية بدلاً من الأسماء فقط.
- نافذة Windows الأصلية لاختيار الصور، مع معاينات الصور في الكمبيوتر.
- زر مقارنة قبل/بعد جنباً إلى جنب كما في سير عمل الفيديو.
- توسيع رسائل الحفظ والفتح والخروج حتى تظهر الكلمات العربية كاملة.

## الجديد في 0.5.0

- معاينة قبل وبعد دائماً جنباً إلى جنب، وشريط صور الدفعة أسفل الشاشة مثل Topaz Photo AI.
- استرجاع تفاصيل الوجه مع إزالة التشويش والحدة، وتنقية الرقبة مع الوجه.
- قوالب تلقائية شاملة للوجه والإضاءة والألوان: طبيعي، بورتريه هادئ، استوديو، تخرج، وسينمائي.
- ضبابية احترافية للخلفية الأصلية مع الحفاظ على الشخص والشعر.
- كي الملابس تلقائياً أو بالفرشاة مع الحفاظ على لون القماش وحماية الحواف والتفاصيل.
- التحقق من سلامة كل ملف بعد الحفظ، وإظهار مجلد النتائج والملفات المحفوظة بوضوح.

المعالجة تعمل على CPU لضمان الاستقرار على جهاز Intel i9-10900K وبطاقة AMD RX 580، ولا تحتاج CUDA ولا ترفع الصور إلى الإنترنت. الاتصال بالشبكة يُستخدم فقط لفحص وتنزيل تحديثات البرنامج من مستودع GitHub بعد موافقتك.

## ملاحظات الجودة

تكبير ×2/×4 في هذه النسخة محافظ مع أدوات التشويش والحدة، وليس نموذجاً توليدياً ضخماً يعيد اختراع تفاصيل مفقودة. إزالة العناصر مناسبة للحبوب والخدوش والأشياء الصغيرة. الشعر الشفاف أو الخلفية القريبة جداً من لون الشعر قد يحتاجان تصحيحاً سريعاً بفرشتي قناع الخلفية.
