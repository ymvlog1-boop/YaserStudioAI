# Yaser Studio AI — المرحلة الأولى

برنامج Windows مكتبي عربي باتجاه RTL لتحرير الصور محلياً.

## التشغيل

افتح `Windows/YaserStudioAI/YaserStudioAI.exe` بالنقر المزدوج. لا تحتاج تثبيت Python أو تنزيل نماذج. إذا نقلت البرنامج إلى جهاز آخر، انقل مجلد `YaserStudioAI` داخل `Windows` كاملاً مع مجلد `_internal`؛ ملف EXE وحده لا يكفي. عند استخدام ZIP، فك ضغط الحزمة بالكامل أولاً.

الحزمة مخصصة لـ Windows x64. تستخدم المعالج CPU وتعمل دون CUDA ودون الاعتماد على بطاقة Radeon RX 580. النماذج والخط العربي مضمّنة؛ المعالجة لا تتصل بخدمة خارجية ولا ترفع الصور. النسخة المحمولة غير موقعة رقمياً ولا تتضمن مثبّت MSI.

## خطوات العمل

1. اختر «استيراد صور JPG» لتحديد صورة أو مجموعة، أو «استيراد مجلد» لصور المجلد مباشرةً. الاستيراد لا يشمل المجلدات الفرعية.
2. اختر الصورة من قائمة الدفعة. تظهر الوجوه المكتشفة تلقائياً.
3. من تبويب «البشرة» حرّك مستويات الحبوب والتجاعيد والنمش/الشوائب والتنعيم بين 0 و100. ابدأ بقيم خفيفة، مثلاً 20–35، وراجع النتيجة.
4. من تبويب «التحديد» ألغِ علامة الوجه لاستثنائه من تنقية البشرة. فعّل «إظهار منطقة تنقية البشرة» لمعاينة حدودها. فرشاة إضافة البشرة تصلح للمناطق الجانبية أو الوجوه غير المكتشفة؛ فرشاة الاستثناء تحمي التفاصيل التي لا تريد تنقيتها. استثناء الوجه له أولوية على فرشاة الإضافة.
5. لتعميم السلايدرات استخدم «تطبيق مستويات التنقية على كل الصور». الكشف يتم بصورة مستقلة لكل صورة. مناطق الفرشاة واستثناءات الوجوه تبقى خاصة بالصورة، ولا تُنسخ إلى أشخاص في صور أخرى.
6. لإزالة عنصر، اختر «فرشاة إزالة عنصر»، ارسم فوقه، ثم اضغط «إزالة العنصر المحدد». زر «تراجع» أو Ctrl+Z يعيد التعديل السابق. التحديد الذي لم يُطبق يمكن مسحه أو التراجع عن آخر ضربة فيه. يمكن تكرار الإزالة على عدة مناطق.
7. من تبويب «الخلفية» اختر صورة من الكمبيوتر. يفصل البرنامج الأشخاص محلياً ويملأ المساحة بالخلفية مع قصها مركزياً لتناسب الصورة. يوجد زر لتطبيق الخلفية على كامل الدفعة، وزر لاستعادة الخلفية الأصلية.
8. اختر مجلد إخراج واحداً، ثم احفظ الصورة الحالية أو الدفعة كاملة. اختر JPG بجودة 98 ومن دون تخفيض عينات الألوان، أو PNG لحفظ دون فقد إضافي. الدقة الأصلية محفوظة؛ تدوير EXIF يُطبق بصرياً بشكل صحيح، لذلك قد يتبادل العرض والارتفاع للصور ذات بيانات التدوير.

تُنشأ أسماء تنتهي بـ `_Yaser`؛ وعند تكرار الاسم يُضاف رقم. لا تُستبدل الصور الأصلية ولا الملفات الموجودة. «إيقاف» يوقف الدفعة بعد انتهاء العملية الحالية؛ الصور التي حُفظت تبقى في مجلد الإخراج. تفاصيل الصور التي فشلت تظهر بعد التصدير.

عجلة الماوس تكبّر الصورة، والسحب في وضع «عرض وتحريك» يحرّكها. زر «ملاءمة الصورة» يعيد عرضها داخل النافذة. اضغط مطولاً «اضغط لعرض الأصل» للمقارنة. المعاينة حتى 1400 بكسل لتسريع التفاعل؛ ملف الحفظ يعالج بالدقة الأصلية، وقد تختلف التفاصيل الدقيقة عن المعاينة.

## حفظ العمل

«حفظ جلسة» يحفظ الإعدادات والفرش والخلفيات والاستثناءات في ملف `.yaser.json`. لا ينسخ الصور نفسها؛ احتفظ بالصور والخلفيات في مواقعها ثم استخدم «فتح جلسة» للعودة. لا يوجد حفظ تلقائي للجلسة. تتوفر آخر 30 حالة تراجع لكل صورة أثناء الجلسة الحالية، ولا يُحفظ سجل التراجع داخل ملف الجلسة.

## حدود المرحلة الأولى

- كشف الوجوه يعتمد YuNet. قد يفوّت وجوهاً صغيرة أو شديدة الميل أو مخفية؛ الفرشاة اليدوية متاحة للتصحيح.
- السلايدرات الأربع تستخدم مرشحات نسيج وصورة مختلفة؛ ليست نماذج مدرّبة لتصنيف الحبوب والتجاعيد والنمش طبياً. القيم العالية قد تخفف تفاصيل ترغب بالاحتفاظ بها.
- فصل الأشخاص يعتمد U²-Net Human Segmentation مع تحسين حواف موجّه بالصورة. يحتفظ بانتقالات ناعمة حول الشعر، لكنه لا يضمن حفظ كل شعرة، وقد تظهر هالات مع الخلفيات المعقدة. لا توجد في هذه النسخة فرشاة مخصصة لتصحيح قناع الخلفية.
- إزالة العنصر تستخدم OpenCV Telea inpainting. مناسبة للبقع والعناصر الصغيرة؛ إزالة الأجسام الكبيرة أو إعادة بناء تفاصيل معقدة قد تُظهر تمويهاً. لا يوجد توليد صور سحابي أو نموذج تعبئة توليدي كبير في هذه المرحلة.
- تتم المعالجة بالتتابع لتقليل الذاكرة، بينما تُخزن قائمة الدفعة كمسارات وتعديلات. زمن المعالجة يعتمد على الدقة وحجم مناطق التعديل وتغيير الخلفية.
- اختُبرت الحزمة في بيئة Windows المتاحة؛ لم يُجر اختبار على جهاز ثانٍ مستقل أو اختبار آلاف الصور عالية الدقة. صورك الخاصة لم تكن متاحة لتقييم الجودة عليها.

## المشروع وإعادة البناء

الكود في مجلد `source`. ثبّت Python 3.11 x64 ثم من ذلك المجلد:

```powershell
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements-lock.txt
.venv/Scripts/python build.py
```

يتحقق `build.py` من وجود النماذج والخط ضمن المصدر، ويمكنه استخدام النسخ الموجودة في حزمة Windows المجاورة. لا يحتاج إعادة تنزيل النماذج. النتيجة في `rebuilt`.

## المكونات ومصادرها

- [OpenCV YuNet](https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet) لكشف الوجوه.
- [U²-Net](https://github.com/xuebinqin/U-2-Net)، وأوزان فصل الأشخاص المنشورة بواسطة [rembg](https://github.com/danielgatis/rembg/releases/tag/v0.0.0).
- [ONNX Runtime](https://onnxruntime.ai/) لتشغيل النموذج على المعالج.
- [OpenCV inpainting](https://docs.opencv.org/4.13.0/df/d3d/tutorial_py_inpainting.html) لإزالة المناطق المرسومة.
- PySide6/Qt للواجهة، Pillow للقراءة والحفظ، NumPy للمعالجة، وخط Noto Sans Arabic.

إشعارات تراخيص المكونات في `licenses`، وبصمات النماذج في `model-manifest.json`. ترخيص PySide6/Qt المستخدم LGPL؛ المكتبات مرتبطة ديناميكياً داخل `_internal`. يمكن إعادة بناء مصدر التطبيق المرفق، وتُسمح تعديلات وتصحيح التطبيق وفق ترخيصه المرفق. راجع تراخيص المكونات عند إعادة توزيعه.
